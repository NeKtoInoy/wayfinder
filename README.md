# Wayfinder

Полевой логгер сетевых ограничений под Android.

Полинезийские навигаторы-уэйфайндеры пересекали океан без карт и приборов —
они читали путь по косвенным признакам: по форме волн, цвету воды, птицам, звёздам.
Это приложение делает то же самое с мобильной сетью: оно не видит правила фильтра
напрямую, но вычисляет их по косвенным сигналам — на каком этапе рвётся соединение,
таймаут это или сброс, проходит ли один SNI и режется другой. Из набора таких
замеров по месту и времени складывается картина того, как на самом деле работают
ограничения.

## Что делает

Снимает «срезы» состояния сети и пишет их в JSON-лог:

- **TCP** к нейтральным и к белым IP — есть ли фильтр по IP (таймаут против сброса);
- **TLS с разным SNI на один IP** — сверяет ли фильтр SNI с адресом (ядро диагностики);
- **UDP/QUIC** — проходит ли UDP вообще;
- **DNS** — резолвит ли оператор заблокированные домены, живуч ли DNS-туннель;
- **контекст** — оператор, тип сети, сигнал, сота, координаты, резолвер.

Два режима: разовый срез по кнопке и фоновый сбор каждые 3 минуты (для прогулки).
Лог экспортируется одним JSON-файлом.

> **Дисклеймер.** Это **диагностический** инструмент — он измеряет и записывает
> поведение сети, ничего не обходит и не туннелирует. Используй его для анализа
> собственного подключения. Ответственность за применение — на тебе.

## Сборка

Проект **полностью текстовый** — бинарных файлов нет, gradle-wrapper генерируется
в GitHub Actions. Заливать можно хоть через веб-интерфейс.

1. Создай репозиторий на GitHub и залей файлы, сохраняя структуру папок
   (на десктопе: Add file → Upload files → перетащи папку целиком).
2. Actions → включи workflows → «Build debug APK» → Run workflow.
3. Через 5–10 мин скачай APK из **Artifacts** → `Wayfinder-debug` → установи.

## Приватные данные (свои серверы и домен туннеля)

В коде их нет — репозиторий можно держать открытым. Значения подставляются при
сборке из секретов репозитория (приватны даже у публичного репа, в логи не попадают).

Settings → Secrets and variables → Actions → New repository secret:

- `WAYFINDER_SERVERS` — узлы в формате `имя|ip|порт|sni;имя|ip|порт|sni`
  пример: `RU|176.0.0.1|8443|www.example.com;SW|89.0.0.1|443|www.example.com`
- `WAYFINDER_TUNNEL` — домен туннеля, например `t.example.xyz`

Нет секретов (например, друг собрал форк) → эти зонды выключены, остальное работает.

Локально: `WAYFINDER_SERVERS="..." WAYFINDER_TUNNEL="..." gradle assembleDebug`

## Что крутить

| Что | Где |
|---|---|
| Интервал фонового замера | `service/SamplerService.kt` → `INTERVAL_MS` |
| Список целей, SNI, DNS-имена | `probe/ProbeTargets.kt` |
| Свои серверы (IP/порт/SNI) | секрет `WAYFINDER_SERVERS` (не в коде) |
| Последовательность зондов | `runner/ProbeRunner.kt` |
| Сам набор зондов | `probe/Probe.kt`, `probe/DnsProbe.kt` |

## Структура

```
app/src/main/java/ru/wayfinder/app/
  probe/      Probe.kt, DnsProbe.kt, ProbeTargets.kt   — зонды и цели
  context/    NetworkContext.kt, LocationProvider.kt    — контекст сети
  data/       Snapshot.kt, Json.kt, LogStore.kt         — модель, JSON, лог
  runner/     ProbeRunner.kt, Config.kt                 — склейка в замер
  service/    SamplerService.kt                         — фоновый сбор
  ui/         MainActivity.kt                           — интерфейс
```

Зависимости текут в одну сторону: ui → runner → probe/context/data.
Переписать UI можно, не трогая зонды, и наоборот. Формат лога версионируется
(`schemaVersion`) — старые логи остаются читаемыми после правок.
